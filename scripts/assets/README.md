manrope-semibold.ttf is a weight-600 static instance of the site’s existing
manrope-latin-variable.woff2, generated with fontTools. It is used only during
build-time social-card rendering. License: OFL.txt.

manrope-cover.ttf is the same weight-600 static face with a distinct Manrope
Cover family name so Pango selects the correct face for article headlines.
It is not shipped as a web font. License: OFL.txt.

Article illustration and reviewed-cover sources belong under illustrations/.
Add artwork for each real article during authoring. The retired design demo and
its images are not required by the featured-image system. Rendering tests create
and remove their own synthetic fixtures.
